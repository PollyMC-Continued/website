About

What is PollyMC-Continued?

PollyMC-Continued is a free, open-source resurrection of the PollyMC project — a Minecraft launcher forked from Prism Launcher that started with a simple promise: play the game without a Microsoft account.

Add an offline account and launch the full game with no demo mode and no restrictions — while still supporting normal Microsoft accounts. Custom skins, per-version instances, mods, and a lightweight Qt interface on Windows, Linux and macOS.

Every line is released under the GPL-3.0 license — focused on user freedom and free redistributability.
