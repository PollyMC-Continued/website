## What's inside

- Static multi-page site built with Astro, with clean URLs like `/downloads/`, `/changelog/` and `/about/`
- Downloads, changelog and contributors are pulled live from GitHub in the browser, so a new release shows up without a redeploy
- Changelog is parsed from `CHANGELOG.md` and shown as one collapsible box per version
- Written in TypeScript, with Rubik as the typeface and WebP backgrounds to keep pages light
- A small Vercel function that carries bug reports from the launcher to Discord

## Bug report relay

`api/report.js` is the other end of the launcher's **Report A Bug** dialog. The launcher sends a JSON `POST` to `/api/report`, and the function forwards it to a private Discord forum channel as a plain message, with a thread title like `Bug: ...` or `Suggestions: ...`.

- The Discord webhook never ships inside the launcher. It stays in Vercel environment variables.
- The endpoint is rate limited and validated to keep spam out.

## Translations

Everything in `public/translation/` is generated. The launcher repo's *Deploy repos and translations* workflow builds it and pushes it here, and Vercel redeploys. Edit anything by hand and it gets wiped on the next sync.

```
public/translation/
├── index_v2.json     # language index with checksums, sizes and progress counts
├── mmc_<lang>.qm     # compiled files the launcher downloads
└── sources/<lang>.ts # Qt Linguist sources for web translation tools
```

Want to fix or add a translation? Change the `.ts` file in the launcher repo, never here.
