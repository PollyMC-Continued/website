# PollyMC-Continued — Website

The official landing page for **PollyMC-Continued**, a community revival of the PollyMC Minecraft launcher.

Live at **[https://pollymc.vercel.app/](https://pollymc.vercel.app/)** — built with Astro, static output.

---

## About the Project

PollyMC-Continued picks up where the original PollyMC left off. It syncs against the [Prism Launcher](https://prismlauncher.org/) upstream, adds NeoForge support, and commits to long-term community maintenance. No Microsoft account required. No DRM. Fully open source under GPL-3.0.

This repository contains only the **website source**. For the launcher itself, see the main [PollyMC-Continued launcher repository](https://github.com/corecommit/PollyMC-Continued).

---

## Stack

- **Astro v7** — multi-page static site with clean URLs (`/changelog/`, `/about/`, `/downloads/`)
- **TypeScript** — changelog parser, client scripts (scroll reveal, download tabs, GitHub data fetching)
- **Client-side data** — changelog, downloads and contributors are fetched live from the GitHub API in the browser
- **Bug report relay** — `api/report.js`, a Vercel serverless function that forwards the launcher's *Report a Bug* form to a private Discord channel (see below)
- **Fonts** — Rubik (Google Fonts)
- **Assets** — WebP backgrounds, PNG screenshots

## Translations

`public/translation/` is **generated by CI and should not be edited by hand**. The launcher repository's *Deploy repos and translations* workflow compiles the `.ts` files from its `translations/` folder and pushes the result here whenever translations change. Vercel then redeploys the site. Any manual change in this folder is overwritten on the next sync.

```
public/translation/
├── index_v2.json        # language index (file, sha1, size, translated/fuzzy/untranslated counts)
├── mmc_<lang>.qm        # compiled translations, downloaded by the launcher
└── sources/
    └── <lang>.ts        # Qt Linguist source files, for web-based translation tooling
```

- The launcher reads `index_v2.json` and the `.qm` files at the top level.
- The `.ts` files live in `sources/` so they can be fetched by tools such as a web translation editor. The language list comes from `index_v2.json`, and each source is at `/translation/sources/<lang>.ts`.
- To change a translation, edit the `.ts` file in the launcher repository, not in this repository.
